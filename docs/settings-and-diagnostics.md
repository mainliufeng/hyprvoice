# 轻量设置与本地诊断

服务空闲时运行 `hyprvoice settings`，打开可用 Tab、方向键、空格、Enter 和 Escape 操作的独立窗口。关闭窗口后回到目标输入框，再触发语音。录音、识别、文字处理或仍有待确认结果时，不能打开或保存设置；不会为切换设置丢弃本次原文、重试请求或目标绑定。

窗口只保存四项：识别后端、文字场景、完成后自动插入、前文辅助。内置场景显示中文名称，自定义 `prompts` 键按字面显示。前文开关旁明确提示会发送光标前已有文字，并显示配置的字符上限；保存不改变这个上限、麦克风来源、接口地址、模型名、提示词或密钥。既有选区修改与文本处理场景仍会发送相应的本次内容，关掉前文辅助并不关闭所有文本请求。

保存之前验证配置类型和场景，并实际初始化新后端。模型加载或配置写入失败时保留当前后端和原配置。配置保存使用同目录临时文件、文件同步、原子替换和相邻协作锁；发现文件被其他操作修改时拒绝覆盖。请在检查外部修改并重新加载配置后再保存。协作锁不能提供针对不遵守锁的编辑器的原子比较与交换，避免同时手工修改配置。

保存中可以取消，包括 Escape；取消在配置替换之前生效。若替换已经完成，就已保存，可用“恢复上次设置”填回草稿，再点击保存。恢复只在本次运行内保留四项设置的上一版，不复制整份配置或密钥；关闭窗口丢弃未保存草稿，重启清除恢复记录。保存后的配置权限为 600；符号链接或非当前用户的配置文件不能被窗口覆盖。

“刷新本地诊断”不录音、不联网。它只报告桌面依赖、本地模型文件、是否完成过当前后端初始化、配置版本与控制目录权限，并只读 PipeWire 图检查指定音源是否存在。发现文件、曾完成初始化或发现音源都不代表本次识别或试麦成功；未指定音源时实际默认路由仍未验证。文本服务只检查配置和环境凭据是否齐全，明确显示未联网验证；界面及诊断 IPC 不返回密钥、环境变量名、模型名或接口地址。当前没有麦克风切换或网络测试按钮。

CLI `hyprvoice settings-status` 返回四项设置、保存状态和消息；`hyprvoice diagnose` 返回上述脱敏本地诊断。`hyprvoice settings-save '{"scene":"correct","auto_commit":false}'` 只接受这四项的 JSON 子集，开始异步保存；以 `settings-status.saving=false` 后的 `message` 检查成功或失败。`settings-previous` 只读取上一版四项，`settings-cancel` 请求取消保存。旧 `backend fun|x-asr` 共用此事务，失败原因在 `status.state.settings_note`；旧 `scene NAME` 仍只改变运行时场景，设置窗口保存场景才会写回文件。

测试方法：构建后 CTest 包含配置事务／诊断检查；`tests/settings_desktop_test.py PRIVATE_RUNTIME EVIDENCE_DIR` 需要预先建立空的私有 Hyprland、AT-SPI 与 D-Bus 会话，脚本自行创建只有虚拟静音来源的 PipeWire 和 loopback 文本服务。它拒绝日常 runtime，所有录音样本须为零。实际生产 App 的键盘操作、失败保留、取消、前文提示及忙碌保护在这个环境验收；不能替代真人麦克风、真实模型质量或日常应用兼容性验收。
