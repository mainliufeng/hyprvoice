# 独立实现范围

本次按用户要求移除从 `voice-input` 移植的 `vad_trimmer.cpp/.h`、`text_join.h`，以及 `asr.cpp` 中旧长录音切分实现。保留的是为 Hyprvoice 自己编写的录音、界面、会话、窗口、剪贴板、文本处理和配置代码。

新实现直接调用公开 sherpa-onnx C API，不包含旧项目头文件，也不加载旧后台或输入法插件。

- `speech.*`：用 Silero 返回人声区间；每帧排空结果队列，边界检查、前后留白及资源释放由本应用负责。没有人声时拒绝输出。短录音保留首尾人声之间的完整音频；长录音保留全部音频，优先选停顿中点分段，每段最多 30 秒。停顿只用于选切点，不裁掉句中较弱的声音。
- `asr.*`：直接初始化本地中英流式／离线模型；实时输出流式结果，结束后执行有界离线任务。任务报错或返回空文字时保留完整流式结果。
- `transcript_text.*`：按 Unicode 字符属性拼接文字，处理中文、拉丁字母、空格和句末标点，拒绝非法 UTF-8。
- `tests/score.py`：标准库独立评分器，检查完整样本 ID、错误、无语音误插字，以及按类别汇总的 CER；可以核对录音 SHA-256。没有调用旧项目测试脚本。

构建验收使用 `/tmp` 独立稀疏工作树，其中没有旧语音项目的源码。模型、VAD、热词和公开录音是单独复制的运行数据；模型路径全部指向 Hyprvoice 自己的资产目录。公开录音及历史识别结果用于相同输入的回归比较，来源许可保留在测试清单中。桌面共存测试仅用现有 Fcitx 拼音，并显式禁用旧语音插件；Fcitx 不是本应用的构建或运行前置条件。

本次没有重做 ASR 模型、GTK、PipeWire 或剪贴板工具。这些通用第三方依赖仍需要正常安装。

2026-10-04 新增的可选 Fun 后端由本应用编写进程适配器，并使用固定版本的 Fun-ASR 上游 CPU runtime 与 llama.cpp。它包含通用第三方识别代码，未使用旧 voice-input 源码；具体来源、许可与实际验收见 [Fun 后端说明](fun-backend.md)。
