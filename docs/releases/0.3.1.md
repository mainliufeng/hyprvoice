# HyprVoice 0.3.1 · 2026-10-31

修复系统升级 sherpa-onnx 后，本地模型文件齐全却无法加载的问题。

- 构建时记录所链接的语音库版本，在向 X-ASR 和 VAD 传入模型配置前核对运行库。
- 库版本变化时明确提示重新构建安装，避免把 C API 结构布局变化误报成模型缺失。
- 保留原模型、后端、快捷键、音频设备、输入方式和文本处理设置；Fun 后端沿用原流程。

## 下载与升级

这是源码发布，附件为 `hyprvoice-0.3.1-source.tar.gz`、`build-verification.txt` 和
`SHA256SUMS`，不包含预编译程序、模型或可选 Fun worker。

```sh
sha256sum -c SHA256SUMS
tar -xzf hyprvoice-0.3.1-source.tar.gz
cd hyprvoice-0.3.1
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
build/hyprvoice --version
```

系统升级 sherpa-onnx 后需重新构建、测试并更新已安装程序；只重启旧程序无效。
安装前处理待确认结果，备份旧程序，保留原配置和模型，再安全重启 `hyprvoice.service`。
从 0.3.0 升级无需修改已有快捷键。依赖与安装步骤见
[README](https://github.com/mainliufeng/hyprvoice/blob/v0.3.1/README.md)。

## 验证范围

本机 Release 构建及源码包独立重建检查 14 组 CTest，覆盖不兼容语音库在模型配置前被拒绝、
空版本与修复时版本查询。本机 sherpa-onnx 2.0.0 下，真实 X-ASR 完成模型自带公开语音及
人工静音回放。精确提交、构建结果与校验值见附件和
[发布核验](https://github.com/mainliufeng/hyprvoice/blob/v0.3.1/docs/releases/0.3.1-verification.md)。

没有采集日常麦克风、读取私人音频或调用外部文字模型；真实口述及外部模型语义质量未验收。
本次不改变识别模型，也不扩大 0.3.0 的识别质量或桌面兼容性结论。
