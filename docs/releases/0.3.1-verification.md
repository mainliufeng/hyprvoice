# 0.3.1 发布核验 · 2026-10-31

本版基于本地 main 已合入的 `9201f86` 语音库兼容保护和 `898dd88` 实际安装验证记录。
发布准备只更新版本号与文档，不改识别算法、模型或用户配置。

## 发布检查

- Arch Linux x86_64，GCC 16.2.1，使用已安装的 sherpa-onnx 2.0.0 C API。
- 特性分支 Release 构建、14 组 CTest、无配置 `--version` 检查。
- 正式提交通过 `git archive --format=tar --prefix=hyprvoice-0.3.1/` 和 `gzip -n` 生成源码包。
  归档不含 `.git`、本机构建产物、用户配置、凭据、模型或测试替身二进制。
- 源码包解压后独立执行相同 Release 构建及 14 组 CTest，核对版本和生产程序哈希。
- GitHub 发布附件为源码包、`build-verification.txt`、`SHA256SUMS`；
  上传后从公开下载链接重新下载，核对校验和、归档提交及文件内容。
  精确提交和实际命令结果保存在发布附件，下载回读和官网部署记录保存在官网仓库文档。

独立 HyprVoice 仓库未配置 GitHub Actions；本机测试不冒充远端 CI。
发布后继续核对 HyprVoice 提交状态及 Mobius 网站更新触发的远端工作流直至终态。

## 模型与安装范围

真实 X-ASR 模型已在 2.0.0 下完成公开模型样本及人工静音回放，
运行版本一致性和配置保留见 [修复记录](../local-model-repair-20261031.md)。
0.3.1 发布构建另行运行同样两条回放，检查语音产生文字、静音无文字。
没有进行真实麦克风口述、外部文字模型语义质量或全量桌面兼容性的新验收。

本次发布不替换已修好的日常程序、不重启用户服务、不改音源或模型。
