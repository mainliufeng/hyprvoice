# HyprVoice 0.3.0 · 2026-10-18

本版让待确认结果可以直接检查、修改和恢复，默认只显示一份干净正文。

- **口述修改与撤销**：F9 修改当前结果，无需选择应用里的文字；先预览再确认，失败保留原正文，可重试或撤销语音修改。
- **来源候选与修改比较**：实时与精修识别的不同片段可点开选择实际来源；手动、F9 和文字处理的修改另行比较，不冒充音频识别分歧。
- **整段编辑与草稿**：保留未应用草稿，后台结果不会覆盖正在编辑的文字；完成编辑后再确认输入。
- **异常恢复**：采集断开、积压或时长上限后尽量收尾有效音频，失败保留最后预览；可能不完整的结果等待确认。复制与输入始终只有正文。
- **保留输入保护**：沿用原窗口、控件与内容核验，包含 Cornice 多桌面的实际 display 编辑；英文长录音尾句的有限修复也在本版内。

## 下载与构建

这是**源码发布**，不包含预编译程序、模型或可选 Fun worker。附件 `hyprvoice-0.3.0-source.tar.gz` 是正式标签的 Git 源码归档，`SHA256SUMS` 用来验证下载内容。

```sh
sha256sum -c SHA256SUMS
tar -xzf hyprvoice-0.3.0-source.tar.gz
cd hyprvoice-0.3.0
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
build/hyprvoice --version
```

依赖、模型配置和首次启动见 [README](https://github.com/mainliufeng/hyprvoice/blob/v0.3.0/README.md)。升级前处理待确认结果、备份旧程序，保留配置与模型。**F9 松开绑定必须改用 `hyprvoice command-release`**，按下仍为 `hyprvoice command`，参见标签内的两种快捷键示例。

## 验证与限制

正式发布从干净 checkout 和上传源码包分别执行 Release 构建、13 组 CTest、无配置版本查询，并检查归档与下载校验和。仓库没有 GitHub Actions；本次测试在本机执行。详见 [发布核验](https://github.com/mainliufeng/hyprvoice/blob/v0.3.0/docs/releases/0.3.0-verification.md)。

功能冻结验收包含隔离 GTK/音频/多桌面流程和公开 WAV 的真实 X-ASR 回放；受控故障和本地 HTTP 合约用于验证流程，**真实麦克风口述与外部文字模型语义质量未验收**。候选和修改比较不保证识别正确，已有漏句、专名与否定错误仍可能出现。
