# 同窗口输入位置保护

自动发送结果需要原窗口及可核验 GTK 编辑控件保持一致：进程、窗口、控件身份、光标、选区范围、字符数及本地全文 SHA256 均参与检查。全文摘要最多处理 65536 个字符，不截断后假称完整核验；正文和摘要不会进入模型请求。前文仍只按原有开关与字符上限发送。关闭前文辅助也不关闭保护检查。

普通听写不覆盖选区。位置变化后保留结果；可在原窗口中先取消选区，点击“核对当前位置”，检查位置及原文／处理结果说明，再点“确认插入当前位置”。确认绑定当次结果、会话及核对过的位置，再次移动或编辑会使确认失效。选择“使用原文”之后的位置确认继续使用识别原文。CLI 对应 `review`，从 `status` 取 `review_token`，然后 `confirm TOKEN`。

指令模式必须有一个非空选区。复制前核验控件，复制出的文字摘要须与该范围对应；提交仍绑定原控件、原范围及原内容。指令不能通过当前位置确认去替换另一个控件或选区，不能把识别到的口述指令当替换结果。选区恢复后可再次核验提交；录音期间目标变化导致未发送模型请求时，应取消并重新选择录音。

密码控件及其后代不读正文，不复制选区，不发送本次文字处理请求，不接受自动粘贴。录音期间监听助手退出或失联后恢复、观察到位置、选区或文字变化会持续阻止本次模型处理及自动提交，即使之后回到原位置。模型请求前另有快照复核。无法识别、读取不稳定、超时、多焦点、超长及非支持控件按无法核验处理，仅保留本地识别文字。可明确点击“复制结果”（选择原文后为“复制原文”）自行粘贴；复制消费本次结果，避免之后再自动提交。

发送前和剪贴板就绪后各核验一次。Hyprland 快捷键发送没有应用回执；已发送不表示应用确认接收。发送状态不确定时结果不可再次自动提交，请检查实际输入框；可选剪贴板恢复失败也不会重启提交。

## 支持与限制

- 当前可靠范围为在本机隔离 GTK 验收中可访问的 Text/Entry、Focused/Editable 控件，Text 接口提供完整稳定快照。不要求应用实现 EditableText 接口，因为发送采用剪贴板快捷键。
- Chrome 与终端未获得同等控件／光标／选区核验承诺；未知控件不会自动发送模型请求或粘贴。原有 Chrome 前文读取测试不能当作本轮目标保护通过。
- Android 不属于这个 Linux/Hyprland 应用的本地验收范围。
- AT-SPI 事件依赖应用正确及时上报，快照读取与快捷键发送跨进程，并非原子事务。无法保证未上报的瞬间变化、最终检查后的极短竞态或应用实际接收；这不等于对任意控件的绝对密码安全保证。
- 启动前同步快照和监听就绪检查有界等待，可能延迟音频开始；真实短按发声起始覆盖仍需真人验收。不能为了速度省去核验。
- 本轮使用合成文字、全零虚拟音源和 loopback HTTP 替身验证保护与恢复流程；未证明真实 ASR/LLM 的识别或保真质量。

测试命令：正常 `cmake --build build -j2` / `ctest --test-dir build --output-on-failure`；`tests/retry_desktop_test.py PRIVATE_RUNTIME EVIDENCE_DIR` 需要已建立的空私有 Hyprland、AT-SPI、PipeWire 环境，脚本拒绝日常 runtime，不可直接对日常桌面运行。
