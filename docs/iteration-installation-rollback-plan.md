## 切换准备

1. 在独立目录固定候选 commit，Release 构建并执行完整 CTest、私有 UI 回归和配置事务测试。沿用已安装模型和 Fun worker；本轮没有重建／验收真实 Fun worker，不借机下载、替换模型或改默认后端。`scripts/install.sh` 会写程序／服务，`--with-fun` 还会构建下载，不能作为未批准的检查命令运行。
2. 确认当前服务已空闲且没有待确认或可重试结果；由用户处理未完成内容。只记录状态布尔值／版本，不保存转录、前文、选区、剪贴板或录音。核对实际安装位置、服务 ExecStart、依赖和运行环境，避免按照历史文档猜测。
3. 在用户私有目录（700）备份**当前实际安装**的程序、需要更改的服务文件和配置（600），记录哈希及权限。密钥环境文件继续原地使用；不读取、输出、上传或另存凭据。配置可能含历史内联凭据，备份也必须只保存在该私有目录，不能进入报告、Git 或 Library。备份之前确认配置没有并发编辑。
4. 对已有配置逐项确认兼容：保留 ASR 后端、模型路径、音源、上下文开关与范围、接口及绑定。新默认 prompts 不覆盖已存在的用户 prompts；如需采用新的纠错／整理文案，必须单独展示并获准修改对应项。默认上下文不会因本次切换扩大。

## 获准后的一次切换

等待用户确认切换窗口后，停止仅本次获准的 Hyprvoice 服务，用已验证构建替换程序，再启动同一个服务。现有服务定义若不需要改变，就不替换；若需要改变，先审阅具体差异再更新。不要禁用、替换或重启 vinput。保留 F8/F9 与现有快捷键配置，不运行无关的 Hyprland reload。不要把“启动成功”写成“语音／文本服务测试成功”。

启动后核对运行程序与候选的 SHA256、空闲状态、后端、四项设置与私有 IPC 权限。只读本地诊断应标记试麦和联网测试未执行。随后在用户明确选择的测试窗口输入公开测试文字，按批准的范围做真人和真实模型验收；不读取日常输入框前文，也不将真实私人数据送到外部模型。

## 放行用例与停止条件

- 实际 F8 按住／轻按、F9 选区修改、停止／取消；原文模式与 X-ASR／Fun 既有流程可用。真实 ASR 与 Fun worker 的识别质量、延迟及首次加载仍需独立验收。
- 忠实纠错与主动整理用公开素材检查数字、金额、日期、小数、版本、否定、条件、不确定性、引用、专名及中英混说。12 个合成 HTTP 用例验证合同与请求策略，不能证明真实模型保真度。
- 真实文本请求的断网、超时、错误与恢复，重试无需再录音，原文和选区保留，成功后重复提交不再插入。真实外部接口测试单独批准，素材公开，不附带日常前文。
- 同窗口双输入框、光标、选区、文本编辑与切走再回来均核验；密码框禁止上下文与云端请求；目标不明时保留结果并允许显式复制。GTK 已隔离验收，Chrome、终端和其他应用不能沿用 GTK 结论；浏览器无障碍配置、焦点事件与粘贴不具备跨进程原子性，逐个应用实测。
- 设置四项保存／取消／恢复、无效配置不覆盖、后端加载失败保留、活动会话拒绝修改；本地诊断不报告未做的网络或音频测试成功。

若发生丢失文字、错误位置插入、重复插入、密码／未知控件向云端发送、配置损坏或日常应用关键操作不兼容，暂停候选验收并进入回退；不为赶排期跳过该验收。Android 不在本 Linux 工具范围。

## 回退

若切换后的服务可以使用，先处理或明确取消待确认内容，再停止该服务。若无法正常停止，按批准的故障处置范围停止；不要重试上屏。恢复此次切换前**实际备份**的程序，只有确实被本次更改的配置／服务文件才恢复；逐项核对期间新增配置，避免整份覆盖用户后续修改。保持私有权限与原凭据文件、模型、绑定和 vinput 状态，启动原服务并核对备份哈希及空闲状态。

若只需撤销窗口内四项设置，且服务仍在同次运行，可“恢复上次设置”填入草稿后保存，不替换程序；该操作不代替版本回退。若备份缺失、原模型／worker 不可用或配置出现未能合并的并发修改，应停止并报告具体阻碍，不伪称回退完成。
