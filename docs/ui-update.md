# 悬浮界面更新 · 2026-10-03

用户反馈旧悬浮界面难看后，更新正式 GTK 界面，并重新安装到本机。

- 统一石墨黑背景、灰白按钮与圆角样式；已移除此前绿色图标、按钮、spinner 和音量条。面板宽度缩小，正文保持可读。
- 顶部以麦克风图标、状态、中文模式和计时分层显示；不再显示内部 `raw` 等模式名。
- 录音时显示真实音量条和结束／取消；等待确认时显示插入／取消。整理结果与原文不同或文本处理报错时，提供使用原文入口；选区修改仍不允许把原始指令作为替换文字。
- 处理时显示真实忙碌状态，错误提示保留细节并可以悬停查看；模式与录音结束提示相匹配。
- 悬浮层保持不接收键盘焦点、无独占区域；正常待机不显示窗口。

实现使用 GTK 自带的 [CSS 属性](https://docs.gtk.org/gtk4/css-properties.html)、symbolic icon 和 [LevelBar](https://docs.gtk.org/gtk4/class.LevelBar.html)，没有增加运行时前端依赖。样式嵌入程序，安装后不依赖工作区 CSS 文件。
