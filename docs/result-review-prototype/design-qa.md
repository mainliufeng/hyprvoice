## 五项检查

- 字体：Noto Sans CJK SC，正文17 px / 350字重 / 26 px行高；标题14 px / 500。候选正文保持17 px，来源小字与正文有层次。浏览器与GTK字形栅格化有轻微差异，属本原型的技术边界。
- 排版：464 px面板、24 px圆角、22 px内侧留白、黑色主按钮；新目标行与编辑/复制/F9操作使高度相较旧版增加约28 px，符合需求。长正文区域有滚动，编辑框可调整高度。
- 颜色：沿用 `#fafafa` 面板、`#45464c`正文、`#36373d`主按钮；异常提示使用现有暖灰色背景。候选当前项轻灰、备选可点击且 hover/focus 有反馈。
- 图像：仅使用系统 Adwaita 麦克风 SVG 原资产，没有模拟波形或AI图像。关闭用有标签按钮，不用自制图形。
- 文案：原型演示标签位于页面外层；浮层保留简短状态、来源、完整性提示及动作。异常用整体提示，无伪造时序错字标记。主按钮“确认输入”，编辑完成回检查而不直接输入。

## 实际交互观察

- 选择备选后当前项与来源上下交换，共用句子没有重复；页面输出采用选定词，不带来源。
- 输入草稿、稍后继续、刷新、继续编辑后，原草稿恢复；完成后显示手动编辑正文且等待确认。
- 手动编辑版本的确认输出与保存文字相同。
- 模拟目标变化后确认输入禁用、复制保留可用，正文不丢失。
- 收尾过程两步均保留预览，禁止输出；失败回退文字后等待确认，输出没有提示标记。
- 无预览且收尾失败时没有虚构文字或候选，复制/编辑/F9/输入均禁用。
- 页面 console error 列表为空，`node --check prototype.js` 与 `git diff --check` 通过。
