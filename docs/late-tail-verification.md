# 英文长录音尾句恢复与逐样本回归 · 2026-10-13

本次 main 改进修复一种 X-ASR 长录音尾部残词：最后一个字母片段出现在语音检测结束之后，结果没有完整句末。只重识别最后一个讲话片段，保留已识别的完整前文；结果需要用户检查后输入。本次没有发布新版本，也没有执行日常安装或服务重启。

## 行为与保护

- 仅处理超过原离线解码预算30秒的录音、最后一个解码job、纯Latin字母假设和疑似不完整尾词。当前job的中文/中英混说假设、普通短句、已完整结束的句子、数值结尾不走这项修复。
- 使用实际token时间戳与现有语音区间。时间戳缺失、非有限、乱序，或token不能精确映射现有文字时保留原结果；不凭音频时长猜补词。
- 原有分段保持。只从最后一次停顿中点重新识别到录音末尾，不裁掉PCM，不重新选择整段流式文字，也不改动较早的识别job。
- 重识别必须保留尾句已完整识别的词前缀；最终拼接还会逐字节保留原前缀的大小写、标点和空格，仅使用新结果的残词及其续文。结果须完整、变长，且固定英语否定/数值词清单与数字标记保持一致。该清单不是自然语言语义证明；也会拒绝确有新增数字/否定的真实续句。
- 空结果、不兼容结果或重识别失败不丢弃原文字。检测到这种尾部异常后显示“部分文字可能听错了，请检查后再点‘输入’”；失败与选区模式同样保留检查提示，不自动输入。

## 实际模型验证

基线为0.2.1 `5577415`，沿用已有本机X-ASR模型、Fun worker与模型。每一版实际回放X-ASR223条、Fun127条，另加20条确定性噪声长音频压力用例；音频SHA256逐条核对，原参考与评分规范不变。

| 范围 | 结果 |
| --- | --- |
| X-ASR原127 | 编辑错误512→488，CER 6.81%→6.49%；仅1条文字改变，其余126条逐字相同 |
| 冻结A45与拼接长3 | 48条文字逐字相同，编辑错误193→193 |
| 冻结B45与拼接长3 | 48条文字逐字相同，编辑错误152→152 |
| Fun原127 | 127条文字逐字相同；既有否定错误仍在 |
| 新增20/10dB长音频压力20条 | 20条文字与警告均逐字相同，没有新增退化 |

唯一变化为公开样本 `long-en_us-dev`：尾部原为 `The major religion in Mone`，现在完整识别为 `The major religion in Moldova is Orthodox Christian.`，与公开参考一致。该条字符编辑错误85→61；新增一次人工确认。较早的整句遗漏和其他词错误仍未修好。所有其它369条结果文字不变，模型返回错误0；逐样本评分没有发现字符退化。本轮没有改变默认后端、模型、用户配置、Hotwords或云端范围。

这些样本包括相关的加噪副本、拼接长录音及已用于诊断的反例；新增20条也是原长音频的确定性衍生，不是370条独立盲测。此结果只证明固定回归中的一个尾句改善，不代表自由口述或真实麦克风质量普遍提升。

## 不用均值掩盖错误

第一候选曾重识别完全没有token的中间讲话段，目标样本编辑错误85→64，但把人名句识别成包含 `Looking to delete` 的错误短语。这种新增语义错误不能因CER下降而放行，整个中间段插入方案已拒绝；没有进入最终实现。

评分器新增 `--fail-on-regression`，要求完整基线，逐条报告编辑数变化和新增模型错误，任何一条退化使命令失败。测试包含“总分改善但一条否定句退化”的反例。该检查不能代替逐句语义审阅，也不能识别所有同义、专名或意图变化。

```sh
python3 tests/score.py MANIFEST.jsonl CANDIDATE.jsonl \
  --baseline BASELINE.jsonl --verify-audio --fail-on-regression
```
